# 千织 7.0 专用启动器 (Chiori Launcher)

![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-brightgreen)

### 一个面向《原神》7.0 的第三方专用启动器，支持官方 CDN 下载、国服 / 国际服离线互转、专用补丁加载与插件注入。

> ⚠️ 本项目仅供**学习与技术交流**使用，请支持官方正版游戏。使用者需自行承担因使用本工具产生的一切后果。

## 主要功能

* **7.0 国服下载与校验**：直连米哈游官方 Sophon CDN，全程锁定 `7.0.0` 清单，下载完毕自动校验哈希并增量补全，绝不误下 7.1 / 6.x。
* **国服 ⇄ 国际服互转（仅限 7.0）**：
  * 国服 → 国际服：使用随包的 `OverseaDiff` 差异资源**本地离线秒转**，无需联网。
  * 国际服 → 国服：走官方 CDN 差分下载缺失组件，同样锁定 7.0.0。
* **插件注入**：基于原生挂起注入引擎，支持 `ChioriPlugin` / `FPS` 插件；帧率解锁、性能悬浮窗、按键热键与配置热替换。
* **节点优选加速**：自动测速选取亚太最低延迟海外 CDN 节点，一键写入系统 Hosts 加速转服（可随时恢复默认）。
* **单文件绿色**：自包含压缩的单个 `exe`，运行数据（`Plugins / logs / 配置`）直接落在 exe 同级目录，整个文件夹可拷贝分发。
* **强制管理员运行**：内置 `requireAdministrator` 清单，启动即提权。

## 怎么用

1. **解压运行**：解压后双击 `千织7.0PC启动器.exe`，在 UAC 弹窗点「是」以管理员身份运行。
2. **选择游戏目录**：点右上角【游戏目录】，选一个**空文件夹**（用于下载）或已有的 7.0 客户端目录。
   * 若所选目录含非 7.0 客户端，启动器会二次提醒风险。
3. **获取 7.0 国际服**：
   * 全新下载：点【开始下载国服】→ 下载完成后在【国服 / 国际服互转】一键转为国际服；
   * 已有国际服：直接选到该目录即可。
4. **开启注入**：顶部切到【注入设置】→ 勾选【启用注入】→ 选择插件。
5. **启动游戏**：回到【启动主页】点【启动游戏】，启动器会自动替换补丁 → 挂起拉起游戏 → 注入插件。

## 注意事项

* **仅支持 7.0**：下载、校验、互转、补丁均严格锁定 `7.0.0`，不支持 6.x、7.1 或其他版本。
* **离线转换需随包资源**：国服 → 国际服依赖 exe 同级的 `OverseaDiff\` 文件夹，请确保与 `exe` 一起分发。
* **首次运行**会在 exe 同级自动生成 `Plugins\ / logs\ / qz_launcher_config.json / Launcher.dll`。

## 构建

开发环境：**Windows + .NET 8 SDK**。

```bash
# 还原并构建
dotnet build QzLauncher/QzLauncher.csproj -c Release

# 发布单文件自包含压缩版（产物：千织7.0PC启动器.exe）
dotnet publish QzLauncher/QzLauncher.csproj -c Release -o publish
```



## 技术栈

* WPF (.NET 8, `net8.0-windows`)
* 米哈游官方 Sophon 资源下载 / 差分转换
* 原生挂起注入引擎（Launcher.dll）+ Rust 动态 Hook 补丁（Astrolabe）
